# NFC 网易云音乐碰碰贴（网页版）

粘贴网易云分享链接 → 网页通过 Web NFC 把 `orpheus://song/{id}/?autoplay=1` 写入 NFC 标签，
手机碰一碰标签，网易云音乐就会打开这首歌并自动播放。

无需安装任何 App，一个本地 HTTPS 服务 + 安卓浏览器即可。

## 工作原理

1. 粘贴分享内容（支持三种形式，自动识别）：
   - 网易云 App 的分享短链：`https://163cn.tv/xxxx`（由本机服务器解析）
   - 完整链接：`https://music.163.com/song?id=29047169&uct2=...`
   - 纯歌曲 ID：`29047169`
2. 拼出 `orpheus://song/{id}/?autoplay=1`（orpheus 是网易云音乐的 URL Scheme）
3. 通过 Web NFC 写入标签，写入**两条记录**（与 NFC Tools 手工写"链接+包名"一致）：
   - URL 记录：`orpheus://song/{id}/?autoplay=1`
   - Android 应用记录（AAR）：网易云包名 `com.netease.cloudmusic`，强制安卓把标签
     分发给网易云——**没有它，部分手机碰自定义协议标签不会有任何反应**
4. 手机碰标签 → 安卓分发 → 网易云音乐打开歌曲并自动播放

## 使用方法

1. 电脑上启动本地 HTTPS 服务（Web NFC 必须走 HTTPS）：

   ```
   方式1：双击 web/start_server.bat
   方式2：命令行执行  python web/server.py
   ```

   服务器会打印访问地址（如 `https://192.168.x.x:8443`）。

2. 手机和电脑连同一个 Wi-Fi，用**安卓 Chrome / Edge** 打开打印的地址：
   - 首次访问出现"不安全"警告属正常（自签名证书）：点 **高级 → 继续访问**
   - 若打不开：看电脑上 Windows 防火墙弹窗是否点了"允许"，确认同一网段

3. 粘贴分享内容 → 自动显示歌曲 ID → 点 **写入 NFC 标签** → 允许 NFC 权限 →
   手机背面贴住标签约 1 秒，提示写入成功后**会自动读回验证**。

4. 点 **读取标签内容** 可随时检查任何标签里写的东西；点 **先试听一下** 直接唤起网易云验证。

## 网页版限制

- 只支持安卓 Chrome/Edge（Chromium 内核）；**iPhone 不支持网页写卡**
- 短链解析依赖本机服务器（`/resolve` 接口，仅允许网易云域名）；若部署在纯静态空间
  （如 GitHub Pages）则解析不了短链，请用完整链接
- 每次写卡都要点一次按钮并授权 NFC（浏览器安全要求）
- 空白未格式化的卡偶尔写入失败，可先用 NFC Tools 格式化一次

## 标签怎么选

- 推荐 **NTAG213（144 字节）/ NTAG215 / NTAG216** 白卡、贴纸、滴胶卡（本工具写入约 81 字节）
- 门禁卡、银行卡、公交卡等 CPU 卡**写不了**（页面会提示）
- 已写入的标签可反复覆盖重写，除非开启了写保护

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 写入报 `Invalid NDEFRecord type` 之类错误 | 刷新页面用最新版；仍报错请提 issue |
| 提示浏览器不支持 Web NFC | 用安卓 Chrome/Edge，且必须 HTTPS 访问 |
| 写入失败 | 手机和标签要一直贴着别中途拿开，重试 |
| 碰标签没反应 | 确认装了网易云音乐；亮屏解锁后碰手机背面顶部；读完标签记得离开页面（网页 NFC 会话开着会截走碰卡事件） |
| 没装网易云的手机碰标签 | 会跳到网易云的应用商店页面（AAR 的正常行为） |
| autoplay 不生效 | 个别网易云版本只打开歌曲页不自动播，歌曲本身能正常打开 |

## 项目结构

```
web/index.html        网页（界面 + 链接解析 + Web NFC 写卡/读卡）
web/server.py         本地 HTTPS 服务器（自动生成自签名证书 + /resolve 短链解析）
web/start_server.bat  Windows 双击启动
web/cert.pem/key.pem  自签名证书（仅限局域网自用，删除后服务器会自动重新生成）
songid.py             歌曲链接解析逻辑（供服务器 /resolve 使用，纯 Python）
requirements.txt      无第三方依赖；仅需电脑上有 Python 3.7+
```
